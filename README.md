# GraphCalc 3DS

GraphCalc homebrew project. GitHub Actions builds both:
- `graphcalc.3dsx` for Homebrew Launcher
- `graphcalc.cia` as a standalone installable HOME Menu application

Push a commit or manually run the workflow in the Actions tab. Download the
`GraphCalc-3DS-builds` artifact and extract it. Install `graphcalc.cia` with FBI.

The CIA is a standalone homebrew application package, not a forwarder.
